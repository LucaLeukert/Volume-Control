# Volume Control

Personal macOS 26 fork of
[Andrea Alberti’s Volume Control](https://github.com/alberti42/Volume-Control).

It maps the keyboard volume keys to Apple Music, Spotify, Doppler, or Swinsian
while one of those players is active, and otherwise controls the system volume.
Holding Command temporarily inverts that behavior.

This fork adds a native animated volume HUD and menu-bar indicator, stable
player-aware volume handling, a native status menu, and updated macOS 26
permission handling.

## Requirements

- macOS 26 or later
- Accessibility permission for global volume-key handling
- Automation permission for each controlled music player
